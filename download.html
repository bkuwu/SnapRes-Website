Before You Switch

Quick setup

A few one-time steps so stretched res actually applies correctly in-game.

01

Add every resolution as a custom resolution

Windows can only switch to a resolution your GPU driver already knows. Add each stretched resolution manually in NVIDIA Control Panel, AMD Software, or Intel Graphics Software so SnapRes can switch to it instantly.

02

Set your GPU scaling to Full Screen

In that same control panel, set the scaling option to Full Screen instead of Aspect Ratio or Centered, so the stretched resolution fills the whole monitor.

03

Turn off the monitor driver

Use the driver card above the resolution buttons in the app. Click Turn off, approve the single Windows permission prompt, and you're done.

04

Set your game to windowed fullscreen and Fill

In your game's video settings, set Display Mode to Windowed Fullscreen and Aspect Ratio to Fill.

05

Only switch once you're in a match

Stretched resolutions apply cleanest once you're fully loaded in. Do it there, not at the menu or agent select.
